# Otilor Graphic Direction

This file is a creative brief for any graphic designer working on the Otilor brand.

The goal is not just to design a logo. The designer should define a coherent visual identity for:

- Logo
- Wordmark
- Brand icon
- Favicon
- Social avatar
- Social banners / launch graphics
- Marketing graphic language
- Lightweight brand patterns and motifs

## 1. What Otilor Is

Otilor is a web-first invoicing app for:

- Freelancers
- Consultants
- Micro-agencies
- Small service businesses

Its job is simple:

- Help users create a polished invoice fast
- Preview before sending
- Send with less friction
- Track what is unpaid, overdue, or paid
- Reduce billing stress

This is not full accounting software.

The product should feel:

- Clear
- Fast
- Professional
- Calm
- Reliable
- Modern

It should not feel:

- Loud
- Playful in a childish way
- Over-designed
- Corporate in a cold way
- Generic fintech clone

## 2. Core Brand Idea

Otilor is about one outcome:

`Get paid with less friction.`

The brand should communicate:

- Order instead of chaos
- Confidence instead of billing anxiety
- Speed without looking cheap
- Trust without looking boring

The visual identity should feel like:

- clean documents
- clear status
- smooth financial flow
- quiet confidence

## 3. Brand Personality

If Otilor were a person, it would be:

- calm under pressure
- sharp
- dependable
- understated
- premium but not luxurious
- local enough to feel real, global enough to scale

Suggested brand tone:

- simple
- smart
- confident
- practical
- warm, but restrained

## 4. Visual Direction

The identity should lean toward:

- minimal
- mature
- modern
- editorial
- software-native

Avoid:

- cartoon-like marks
- childish mascots
- fake 3D fintech style
- overused money symbols
- loud gradients everywhere
- logos that depend on tiny details

The best direction is something that can sit comfortably on:

- a SaaS landing page
- an invoice PDF
- a favicon
- a mobile app icon later

## 5. Color Direction

These are the current product colors and should guide the brand system.

### Primary Brand Blue

- `#0B6BFF`
- `#075CE0`
- `#064CB7`

Use for:

- primary brand recognition
- CTA energy
- core logo accent if needed

### Supporting Success Green

- `#0E9F6E`

Use for:

- payment success
- trust signals
- subtle accents only

### Supporting Info Blue

- `#0284C7`

Use for:

- secondary highlight
- subtle graphic depth

### Neutrals

- `#FFFFFF`
- `#F8FAFC`
- `#F1F5F9`
- `#E2E8F0`
- `#475569`
- `#1E293B`
- `#0F172A`

Use for:

- the main logo environment
- typography
- monochrome lockups
- invoice and document styling

### Color Notes

- Blue should stay dominant.
- Green should support, not compete.
- Neutral darks should carry most of the mature feel.
- Avoid purple-heavy palettes.
- Avoid rainbow or highly saturated combinations.

## 6. Typography Direction

Current product direction uses:

- `Manrope`

Graphic work should feel compatible with:

- modern geometric sans-serif forms
- tight spacing
- clean, premium wordmarks

Wordmark should feel:

- sharp
- balanced
- easy to read
- strong at small and medium sizes

Avoid:

- overly futuristic letterforms
- playful rounded bubble type
- handwritten or script styles

## 7. Logo Direction

The designer should explore both:

- a wordmark
- a symbol / icon mark

The logo should be usable in:

- full horizontal lockup
- symbol only
- monochrome
- reverse on dark background

### What The Logo Should Suggest

- invoices / documents
- structure
- flow
- completion
- payment confidence

### Strong Symbol Directions To Explore

- a refined document corner / folded page
- a clean check / approval shape
- a flow line moving forward
- an abstract receipt / invoice grid
- a simplified mark built from `O`
- a shape that hints at clarity, movement, and completion

### Weak Directions To Avoid

- naira sign as the whole logo
- dollar signs
- coins
- cash stacks
- piggy banks
- random lightning bolt
- generic arrows with no personality
- anything that looks like a crypto logo

## 8. Pattern / Graphic Motif Direction

The brand should also have a supporting graphic language beyond the logo.

Patterns and motifs can draw from:

- invoice rows
- subtle ledger lines
- rounded rectangular blocks
- clean grid fragments
- status dots
- curved flow paths
- folded-paper geometry
- simple receipt edges

These should be:

- subtle
- sparse
- modular
- usable in backgrounds, banners, and launch graphics

Avoid busy pattern systems.

The pattern language should support the brand, not dominate it.

## 9. Favicon Direction

The favicon should be:

- simple
- bold
- readable at 16x16 and 32x32
- based on the icon mark, not the full word

Good favicon options:

- abstract `O`
- document-inspired symbol
- simplified flow/check mark

Bad favicon options:

- full wordmark
- tiny invoice details
- thin line-only mark with weak contrast

The favicon should work in:

- full color
- dark mode browser tab
- light mode browser tab

## 10. Social and Marketing Graphics

The designer should define how Otilor looks in:

- X / Twitter banner
- LinkedIn banner
- Instagram / launch posts
- product announcement cards
- pitch deck / presentation headers
- waitlist or launch graphics

Graphic direction should use:

- whitespace
- clear typography
- one primary color move
- subtle pattern support
- document / invoice inspired framing

Avoid noisy promo designs.

## 11. Invoice / Product Brand Compatibility

The identity must fit inside the actual product.

That means:

- logo should look credible on an invoice PDF
- logo should not overpower invoice content
- icon should look clean inside navbars and app headers
- brand colors should still work with business UI states

The designer should imagine the mark appearing on:

- invoice header
- dashboard nav
- empty state illustration
- favicon
- app splash screen

## 12. Deliverables Needed

Ask the designer for:

- primary logo
- secondary logo
- icon mark
- wordmark
- monochrome versions
- reverse versions for dark backgrounds
- favicon set
- social profile icon
- brand pattern or motif set
- color palette file
- typography recommendations
- usage guide

Preferred export formats:

- `SVG`
- `PNG`
- `PDF`

If possible, also request:

- `AI` or `Figma` source

## 13. Usage Rules To Define

The designer should include:

- minimum clear space
- minimum size
- incorrect usage examples
- approved background pairings
- color variations
- icon-only usage rules

## 14. Creative Guardrails

The final identity should feel like:

- a serious software product
- built for real work
- easy to trust
- memorable without shouting

The final identity should not feel like:

- a playful startup for teens
- a generic banking app
- a crypto exchange
- a tax agency tool
- a random invoice template marketplace

## 15. One-Line Brand Summary For The Designer

Design Otilor as a calm, modern invoicing brand that helps freelancers and small teams create invoices quickly, look professional, and get paid with less friction.
